Delete an account

You can request removal of your BloomDoc account, plants, scans, care schedules, chat history and stored photos. Removing the app from your phone is not an account-deletion request.

If you still have access to BloomDoc, open Profile → Danger zone → Delete account. The app keeps a private status receipt on your phone. Keep that receipt until cloud deletion is confirmed complete.

Lost access to a Guest User?

If the original phone or app installation is gone, use the recovery code you previously saved from BloomDoc. It can only request deletion of the exact Guest User that created it; it cannot open the garden or sign you in.

This permanently deletes that Guest User and its cloud data. Anyone with the code can request this deletion. Keep a separate copy until deletion is complete. Never email it, share it with support, or put it in a web address.

Request permanent Guest User deletion

Paste the complete code saved from BloomDoc. This page sends it directly to BloomDoc's deletion service and does not save it in browser storage.

An accepted or pending request, an empty screen, or a network timeout is not completed deletion. To check again, paste your separately saved code and confirm again. This page never submits automatically. Do not assume photos were removed because the app stopped showing them.

Saved accounts and support

If you saved your account with email or Sign in with Apple, sign in to BloomDoc and delete it from Profile. If you cannot sign in, email BloomDoc support with an account-deletion request. Use the address associated with your BloomDoc account if you can. We must verify ownership before acting on an account; an email address alone is not proof.

Do not include your password, sign-in token, deletion receipt, recovery code or private plant photos. A support message is not confirmation that deletion has completed.

No recovery code?

A Guest User is tied to its original app account, not an email or display name. If the installation and recovery code are both gone, support cannot safely identify it from a device name or a plant description and will not guess which account to remove.

Subscriptions are separate

Deleting a BloomDoc account or uninstalling the app does not cancel an Apple App Store or Google Play subscription. See Support for subscription-management instructions.
